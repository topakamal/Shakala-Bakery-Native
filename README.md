# Shakala Bakery POS Native Android

Versi ini tidak memakai browser, Capacitor, Web Bluetooth, atau service worker.
Build dilakukan dari HP melalui GitHub Actions. Upload seluruh isi folder ke repository GitHub, lalu buka Actions dan jalankan `Build Shakala Bakery Native APK`.

Bluetooth memakai Bluetooth Classic RFCOMM/SPP untuk printer yang sudah dipairing. Android akan meminta izin Nearby devices saat fitur printer pertama kali digunakan.
